# Gesture-X

Real-time AI gesture operating system built with React, MediaPipe Hands, and Canvas API.

## Features

- Real-time hand tracking
- Gesture recognition
- Air drawing system
- Interactive visual effects
- Gesture-based controls
- Modular architecture

## Tech Stack

- React
- Vite
- MediaPipe Hands
- JavaScript
- Canvas API
- Framer Motion

## Installation

```bash
git clone https://github.com/yourusername/Gesture-x.git

cd Gesture-x

npm install

npm run dev
